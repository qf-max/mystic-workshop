# 密契工坊 · 禁忌炼金卡牌堆叠桌游

双面卡牌堆叠德式桌游的可玩网页版（单文件、完全自包含，浏览器直接运行，无需服务器）。

## 游戏简介（快速上手）

- 双面卡：正面 = 6 资源位 + 订单 + 技能 + 得分；反面 = 建筑效果（建造后持续生效）
- 打出的卡组成「牌组」：组内**未被遮盖的资源即你拥有的资源**（资源按牌组统计，不消耗）
- 每次打牌单独选择保留方式：保留材料（只遮左上）或保留技能（遮左上+左下+下中）
- 一回合 2 行动点：抽卡 / 打牌 / 建造（仅手牌）/ 触发技能（1AP）
- 技能：组内**对应材料可见数 ≥ 卡牌等级**才可发动；触发时连锁免费触发组内全部技能
- 2~4 人局（真人/AI 混战），结束方式可选目标分数 / 固定回合 / 先到先止
- 牌堆分 L1~L5 等级，随回合解锁，解锁高级后低级仍在
